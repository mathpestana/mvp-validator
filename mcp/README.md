# mcp

Servidor MCP (Fase 5), feito com o SDK oficial de MCP em Python. Permite que agentes de código (Claude Code e outros) chamem o simulador direto do fluxo de desenvolvimento.

Ferramentas previstas:

| Ferramenta | O que faz |
| --- | --- |
| `criar_painel` | Cria um painel de personas a partir de critérios |
| `rodar_teste` | Roda um experimento numa versão do MVP com um painel e tarefas |
| `obter_relatorio` | Devolve o relatório e os achados de um experimento |
