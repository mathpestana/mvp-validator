# Skill plantar-bug

Planta e cataloga, um por vez, bugs de propósito num app de exemplo, para servir de gabarito na medição de agentes de teste (quantos defeitos acham e quantos alarmes são falsos). Cada bug ganha um ID, um comentário no código e uma linha num catálogo `BUGS.md`.

Para usar em outro projeto: copie esta pasta para o `.claude/skills/` do seu projeto e reinicie o Claude Code. Ela espera uma pasta `app-exemplo/` com `AGENTS.md` e `BUGS.md` no formato deste repositório; ajuste os caminhos no `SKILL.md` se os seus forem outros.
