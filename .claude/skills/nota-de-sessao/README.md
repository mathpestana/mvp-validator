# Skill nota-de-sessao

Escreve a nota de encerramento de uma sessão de trabalho com o Claude Code: o que foi feito, o que foi decidido, o estado real do projeto e os próximos passos. A sessão seguinte começa lendo essa nota, em vez de reconstruir o contexto do zero.

Para usar em outro projeto: copie esta pasta para o `.claude/skills/` do seu projeto e reinicie o Claude Code. Ela grava as notas em `docs/sessoes/`; crie essa pasta ou ajuste o caminho no `SKILL.md`, e adapte o modelo do `reference.md` ao seu fluxo.
