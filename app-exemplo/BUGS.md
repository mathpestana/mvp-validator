## Ideias para plantar

Ainda não implementadas. Ao implementar, mova para a tabela acima com um ID.

**Quebrado**

- O botão "Criar conta" não faz nada quando o e-mail tem letra maiúscula.
- O formulário de cadastro apaga todos os campos quando a senha é recusada.
- A página de produto dá erro quando o nome tem acento.

**UX confusa**

- O campo de telefone exige um formato que não é explicado.
- O botão principal é cinza e parece desativado.
- O preço só aparece depois do cadastro.
- A mensagem de erro diz apenas "Algo deu errado".

**Acessibilidade**

- Imagens sem texto alternativo.
- Texto de ajuda com contraste baixo.
- Não dá para concluir o cadastro usando só o teclado.
